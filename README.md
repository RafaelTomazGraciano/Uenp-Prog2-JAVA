Repositório de códigos desenvolvidos durante as aulas da disciplina **Programação 2** na [UENP](https://uenp.edu.br/).

## Sobre o Projeto

Este repositório reúne alguns dos códigos escritos ao longo do curso de Programação 2, ministrado na Universidade Estadual do Norte do Paraná ([UENP](https://uenp.edu.br/)). Os exemplos aqui presentes abrangem conceitos fundamentais e intermediários de Java, incluindo:

- Classes, objetos, construtores e métodos
- Manipulação de strings e arrays
- Herança e polimorfismo
- Interfaces
- Testes básicos de unidade

O objetivo deste repositório é servir como referência de estudo e consulta para estudantes e interessados em programação orientada a objetos com Java.

## Estrutura do Repositório

```
1.Classes_Objetos_Contrutores_Metodos/   # Exemplos de classes, objetos, construtores e métodos
3.String_Array/                          # Exercícios com strings e arrays
4.Heranca/                              # Exemplos de herança, polimorfismo e testes
5.interface/                            # Implementação de interfaces e comparadores
```

Cada pasta contém arquivos-fonte Java (`.java`) organizados por tema.
